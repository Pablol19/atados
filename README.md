# Atados

Juego cooperativo para 2 jugadores: dos esquiadores atados por una cuerda bajan una montaña infinita esquivando obstáculos. Gana quien más aguante.

- **Local:** los dos en el mismo teclado (WASD y flechas) o con mandos.
- **Online:** uno pulsa "Crear partida online" y le pasa el código de 4 letras al otro. La conexión es directa entre navegadores (WebRTC con PeerJS).

Hecho con [Three.js](https://threejs.org) y [PeerJS](https://peerjs.com). Todo el juego está en `index.html`.
